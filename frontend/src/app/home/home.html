How it works

Three steps. All crypto happens in your browser.

1

Create an account

Your password runs through 200,000 rounds of PBKDF2 to derive your personal encryption key — we never store your password or key.

Why SecureTransfer?

🔑

One master key

Log in once. Every file you upload is encrypted with a single vault key derived from your password — no per-file passphrases to remember.

🕵️

Zero-knowledge server

The server stores only encrypted bytes. Even if the database is breached, attackers get ciphertext they cannot read without your password.

📡

Anomaly detection

Every transfer is analysed with Z-score and IQR algorithms. Unusual file sizes trigger an automatic alert so you know if something looks off.

⏱

24-hour share links

Generate a time-limited link for anyone. Links expire automatically — no need to remember to revoke them. Recipients decrypt in their browser.

🛡

Brute-force protection

Login attempts are rate-limited to 3 per 10 seconds. Repeated failures are blocked before an attacker can guess your password.

🌐

No plugins needed

All encryption uses the browser's built-in Web Crypto API — no extensions, no downloads, no trust in third-party software.
